For each tool, confirm with the tool's vendor or operator:
  [ ] Tool's HSMS is configured as PASSIVE (we are ACTIVE, we initiate connect)
      ACTIVE/PASSIVE determines which side initiates the connection.
  [ ] No other host/MES occupies this tool's HSMS-SS session. The single-peer
      limit is the tool's single-session HSMS-SS constraint, not a consequence
      of choosing ACTIVE or PASSIVE.
  [ ] DaVinci/FabLink uses E30-style reports for full-detail collection.
      E40 may still provide coarser lifecycle data. Confirm with the tool owner
      before changing report style or restarting the Host Interface.
  [ ] Alarms are enabled on the tool (typical default). If they are NOT, set
      enable_alarms: true for that machine in production.yaml so the middleware
      sends S5F3 (Enable All Alarms) on connect. enable_alarms defaults to
      false because not every tool accepts a host "enable all" S5F3 - confirm
      with the tool owner before enabling it.

OPTIONAL:
  [ ] NSSM (Non-Sucking Service Manager) - nssm.exe copied to e.g.
      C:\Tools\nssm\nssm.exe (needed only if you want auto-start on boot)
